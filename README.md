# Schedulo — WhatsApp message scheduler (Android)

1. Open this folder in Android Studio → let Gradle sync.
2. Run on a real phone with WhatsApp installed.
3. In the app: tap "Enable" → Accessibility → Schedulo → On. Allow exact alarms + notifications.
4. Schedule a message 2 min ahead to test. Keep screen lock off (or use "Ask before sending").

Disable battery optimization for Schedulo on Xiaomi/Oppo/Vivo/Realme, or alarms get killed.
